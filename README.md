# TaskFlow

Aplicación web para la gestión personal de tareas, desarrollada
con Laravel y MySQL.

## Funcionalidades

- Registro de tareas.
- Edición y eliminación de tareas.
- Asignación de prioridades.
- Seguimiento del estado de las tareas.
- Búsqueda por título.
- Filtros por estado y prioridad.
- Identificación de tareas vencidas.

## Tecnologías

- PHP
- Laravel
- MySQL
- HTML
- CSS
- JavaScript
- Apache

## Requisitos

- PHP y las extensiones requeridas por Laravel.
- Composer.
- MySQL.
- Apache.
- Git.

## Instalación

1. Clonar o descargar el proyecto.
2. Instalar las dependencias con Composer.
3. Copiar `.env.example` a `.env`.
4. Configurar la conexión a la base de datos.
5. Generar la clave de la aplicación.
6. Ejecutar las migraciones.
7. Configurar Apache para apuntar a la carpeta `public`.
